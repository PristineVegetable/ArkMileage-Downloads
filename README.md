# Ark Mileage for Android

[Download Ark Mileage](https://github.com/PristineVegetable/ArkMileage-Downloads/releases/latest/download/Ark-Mileage.apk)

For Ark Care Principles staff. No GitHub account is needed to download the installer.

1. Download the APK on your Android phone and install it.
2. When updating, install over Ark Mileage Connected and keep existing app data.
3. For first-time setup, ask your manager for an activation email. Open Settings > Connect to Ark People and enter your registered email and the private code within 30 minutes.

Contact your manager if installation is blocked or you need help signing in.
